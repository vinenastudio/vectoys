# Security policy

## Report a problem

Please report security problems privately. Do not open a public issue.

- Use GitHub private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**.
- Or email mert@vinena.studio.

We reply as soon as we can and tell you when a fix ships.

## What counts

- An item that runs code it should not, for example a network call, `eval` or a `<script>` element.
- The command line tool writing files outside the project folder.
- Tampering with the registry, for example an item or index that is changed after review.

## Supported versions

Only the latest `0.x` release gets security fixes.
